Code for exploring, interpreting, and exporting to Haskell USDA json datasets of nutrient composition of various foods.

Data source: https://fdc.nal.usda.gov/download-datasets.html
Other sources (mostly derived from USDA):

    https://www.myfooddata.com/articles/complete-vegetarian-protein-foods.php
    https://foodb.ca/examples/apple
